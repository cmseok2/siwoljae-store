# 사주서가 커머스 홈페이지

프리미엄 사주 상품을 소개하고 장바구니와 결제 단계를 제공하는 반응형 홈페이지입니다.

## 로컬 실행

```bash
npm ci
npm run dev
```

## 수정 위치

- 상품과 화면 문구: `app/page.tsx`
- 색상과 레이아웃: `app/globals.css`
- 서버 상품 가격: `lib/products.ts`
- 결제 공통 인터페이스: `lib/payment.ts`
- 결제 준비·승인 API: `app/api/payments`

상품 가격은 결제 조작 방지를 위해 화면과 서버 상품 목록을 함께 수정해야 합니다.

## 결제사 연결

현재는 테스트용 `MockPaymentGateway`가 연결되어 있습니다. 결제사를 정하면 `PaymentGateway` 인터페이스를 구현한 토스페이먼츠 또는 포트원 어댑터를 추가하고 환경변수에 키를 등록하면 됩니다. 비밀키는 `.env`에만 저장하고 GitHub에는 올리지 마세요.
